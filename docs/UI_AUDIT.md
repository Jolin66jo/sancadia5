## Route and game coverage

Explicit routes are `/`, `/games`, `/games/:gameId/rules`, `/games/:gameId/settings`, `/games/:gameId`, `/settings`, `/stats`, `/login`, `/signup`, `/social`, `/shop`, `/profile`, and `/admin`, followed by `*` for not found. The game route dynamically resolves 21 available games plus 10 catalog entries that share the coming-soon screen. Separate pre-game states exist for Noughts and Crosses, Connect 4, Gomoku, Xiangqi, Reversi, Checkers, Battleships, Mastermind, Bulls and Cows, and Hangman; Latrunculi has a custom main menu. Stratego, Sjoelen, Ganzenbord, Dots and Boxes, Mancala, Dominoes, Ludo, Snake, 2048, and Minesweeper start directly on their game screen. Battleships also has a fleet-placement phase after its match setup.

## Validation status

- Headless Chromium on November 11, 2026: all explicit route families and representative game routes rendered at 360×640 with no horizontal document overflow. The `/games/seega` path redirected to the games catalog as expected.
- At 320px width, `/`, `/games`, `/games/2048/rules`, `/settings`, and `/games/minesweeper` had no horizontal document overflow. At 1365×900, Ludo, Minesweeper, and Latrunculi had no horizontal document overflow.
- The Home `Play` link was inside the initial 360×640 viewport. Keyboard Tab focused a visible link, the reset dialog fit in the viewport and closed on Escape, and all eight Ludo token controls measured at least 44×44px.
- A rules deep link loaded directly, survived refresh, and worked with both the app back link and browser back. The unknown-game fallback displayed. No uncaught page errors or browser console errors were observed in the run.
- `npm run typecheck`, `npm run lint`, and `npm test` passed; Vitest reported 48 files and 280 tests passing.
- `npm run format:check` failed because Prettier reports 206 files in the repository as unformatted; consequently `npm run check` stops at that formatting step. No formatting sweep was applied.
- Still pending: screen-reader and complete keyboard-only review, text zoom, contrast measurement in the browser, performance, PWA/offline behavior, storage-corruption behavior, broad game-state/lifecycle testing, and screenshots. The browser audit is therefore not complete.
